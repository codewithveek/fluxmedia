# API Reference

Complete API documentation for FluxMedia packages.

## MediaUploader

The main class for uploading files. Supports fallback providers, transactional uploads, and plugin orchestration.

### Constructor

```typescript
new MediaUploader(
  provider: MediaProvider,
  plugins?: FluxMediaPlugin[],
  config?: MediaUploaderConfig
)
```

**Parameters:**

| Parameter  | Type                  | Description                                         |
| ---------- | --------------------- | --------------------------------------------------- |
| `provider` | `MediaProvider`       | Primary storage provider                            |
| `plugins`  | `FluxMediaPlugin[]`   | Optional array of plugins to register               |
| `config`   | `MediaUploaderConfig` | Optional configuration for fallback, error handling |

### MediaUploaderConfig

```typescript
interface MediaUploaderConfig {
  fallbackProvider?: MediaProvider;
  fallbackOnErrors?: MediaErrorCode[];
  onFallback?: (error: MediaError, fallbackProvider: MediaProvider) => void;
}
```

| Option             | Type               | Description                                                                       |
| ------------------ | ------------------ | --------------------------------------------------------------------------------- |
| `fallbackProvider` | `MediaProvider`    | Provider to use when primary fails                                                |
| `fallbackOnErrors` | `MediaErrorCode[]` | Error codes that trigger fallback (default: network, rate-limit, provider errors) |
| `onFallback`       | `function`         | Callback when fallback is triggered                                               |

**Example:**

```typescript
import { MediaUploader, MediaErrorCode } from '@fluxmedia/core';

const uploader = new MediaUploader(primaryProvider, [analyticsPlugin], {
  fallbackProvider: backupProvider,
  fallbackOnErrors: [
    MediaErrorCode.NETWORK_ERROR,
    MediaErrorCode.RATE_LIMITED,
    MediaErrorCode.PROVIDER_ERROR,
  ],
  onFallback: (error, provider) => {
    console.warn(`Falling back to ${provider.name}: ${error.message}`);
  },
});
```

### Methods

#### upload(file, options?)

Upload a single file. Runs `beforeUpload` hooks, the provider upload (wrapped by `wrapUpload` hooks such as retry), then `afterUpload` hooks. Fails over to the fallback provider on qualifying errors (never for streams).

```typescript
async upload(file: UploadInput, options?: UploadOptions): Promise<UploadResult>
```

#### File references

Every method below that takes a `ref` accepts a file ID / storage key or the `UploadResult` returned by `upload()`. Passing the result routes the call to the provider that stored the file (after a failover) and passes hints such as Cloudinary's resource type.

```typescript
type FileRef = string | UploadResult;
```

#### delete(ref) / deleteMultiple(refs)

```typescript
async delete(ref: FileRef): Promise<void>
async deleteMultiple(refs: FileRef[], options?: { concurrency?: number }): Promise<void>
```

Plain IDs are deleted with the provider's batch API (S3/R2 `DeleteObjects`). Throws `DELETE_FAILED` with `details.failedIds` when some deletes fail. Deleting a missing file succeeds.

#### get(ref) / exists(ref)

```typescript
async get(ref: FileRef): Promise<UploadResult>     // FILE_NOT_FOUND if missing
async exists(ref: FileRef): Promise<boolean>
```

#### getUrl(ref, transform?) / getUrlAsync(ref, transform?)

`getUrl` is synchronous; `getUrlAsync` also runs `beforeGetUrl` hooks. For private storage the URL is not readable — use `getSignedUrl`.

```typescript
getUrl(ref: FileRef, transform?: TransformationOptions): string
async getUrlAsync(ref: FileRef, transform?: TransformationOptions): Promise<string>
```

#### getSignedUrl(ref, options?)

Time-limited URL for reading a private file.

```typescript
async getSignedUrl(ref: FileRef, options?: {
  expiresIn?: number;        // seconds, default 3600 (S3/R2/GCS/Azure max 7 days)
  downloadAs?: string;       // force a download with this filename
  transform?: TransformationOptions; // Cloudinary with token auth
}): Promise<string>
```

#### createUploadUrl(options)

Signed target for a direct browser upload. Expose it through `createSignedUploadHandler` (see Secure Uploads) rather than directly.

```typescript
async createUploadUrl(options: {
  contentType: string;       // signed on S3, R2 and GCS
  size?: number;             // exact size on S3/R2, upper bound on GCS
  filename?: string;
  folder?: string;
  expiresIn?: number;        // default 600
  uniqueFilename?: boolean;
  metadata?: Record<string, unknown>;
  tags?: string[];
  cacheControl?: string;
  contentDisposition?: string;
  public?: boolean;
}): Promise<SignedUploadTarget>

interface SignedUploadTarget {
  uploadUrl: string;
  method: 'PUT' | 'POST';
  headers?: Record<string, string>; // send with PUT
  fields?: Record<string, string>;  // send before "file" with POST
  storageKey: string;
  publicUrl?: string;
  expiresAt: Date;
  provider: string;
}
```

#### list(options?) / listAll(options?)

```typescript
async list(options?: { folder?: string; limit?: number; cursor?: string }): Promise<{
  items: UploadResult[];
  nextCursor?: string;
}>

for await (const file of uploader.listAll({ folder: 'invoices' })) {
  // follows cursors for you
}
```

#### search(query)

Supported by Cloudinary (Search API). Other providers throw `NOT_SUPPORTED`; use `list`.

#### copy(ref, toId) / move(ref, toId)

```typescript
async copy(ref: FileRef, toId: string): Promise<UploadResult>
async move(ref: FileRef, toId: string): Promise<UploadResult>
```

#### download(ref)

```typescript
async download(ref: FileRef): Promise<{
  body: ReadableStream<Uint8Array>;
  contentType?: string;
  size?: number;
}>
```

#### updateMetadata(ref, metadata)

Replaces the file's custom metadata (top-level primitive values only).

```typescript
async updateMetadata(ref: FileRef, metadata: Record<string, unknown>): Promise<void>
```

#### uploadMultiple(files, options?)

Uploads with a concurrency limit, running plugins for each file. When any upload fails it throws a `MediaError` whose `details.succeeded` holds the results that did upload and `details.failed` the errors by index.

```typescript
async uploadMultiple(
  files: UploadInput[],
  options?: UploadOptions & { concurrency?: number } // default 3
): Promise<UploadResult[]>
```

#### uploadWithTransaction(file, options, callbacks)

Upload, then commit; if the commit throws, the upload is rolled back (`onRollback`, or deleted from the provider that stored it).

```typescript
async uploadWithTransaction<T>(
  file: UploadInput,
  options: UploadOptions,
  callbacks: TransactionCallbacks<T>
): Promise<{ uploadResult: UploadResult; commitResult: T }>

interface TransactionCallbacks<T> {
  onCommit: (result: UploadResult) => Promise<T>;
  onRollback?: (result: UploadResult, error: Error) => Promise<void>;
}
```

**Example:**

```typescript
const { uploadResult, commitResult } = await uploader.uploadWithTransaction(
  file,
  { folder: 'documents' },
  {
    onCommit: async (result) => {
      return await db.documents.create({ storageKey: result.storageKey, provider: result.provider });
    },
  }
);
```

#### ready()

Resolves once constructor plugins are initialized; rejects if one's `init()` failed.

#### supports(feature)

Check if provider supports a feature.

```typescript
supports(feature: string): boolean
```

#### use(plugin)

Register a plugin. Calls `plugin.init()` if defined.

```typescript
async use(plugin: FluxMediaPlugin): Promise<this>
```

## Types

### UploadInput

Union type for all accepted upload inputs:

```typescript
type UploadInput = File | Buffer | Readable | ReadableStream;
```

Supports browser `File` objects, Node.js `Buffer`, Node.js `Readable` streams, and web `ReadableStream`.

### UploadOptions

```typescript
interface UploadOptions {
  folder?: string;
  filename?: string;
  public?: boolean;
  tags?: string[];
  metadata?: Record<string, unknown>;
  transformation?: TransformationOptions;
  onProgress?: (percent: number) => void;
  onByteProgress?: (loaded: number, total: number | undefined) => void;
  uniqueFilename?: boolean;     // Append a random suffix (default: true)
  contentType?: string;         // Required for streams
  cacheControl?: string;
  contentDisposition?: string;
  signal?: AbortSignal;
  providerOptions?: Record<string, unknown>;
}
```

| Option | Type | Description |
|--------|------|-------------|
| `folder` | `string` | Destination folder. Sanitized: `..` segments and unsafe characters are removed |
| `filename` | `string` | Custom filename (without extension), sanitized the same way |
| `public` | `boolean` | Visibility. Cloudinary stores `false` as `authenticated`; S3 applies an ACL with `useAcl`; requests a bucket cannot honour fail |
| `tags` | `string[]` | Tags (S3/R2 object tags, Cloudinary tags) |
| `metadata` | `Record<string, unknown>` | Custom metadata. Only top-level string/number/boolean values are stored; `_`-prefixed keys and nested objects stay in-process |
| `transformation` | `TransformationOptions` | Apply transformations on upload (Cloudinary) |
| `onProgress` | `(percent: number) => void` | Normalized 0-100 progress callback |
| `onByteProgress` | `(loaded, total) => void` | Byte progress; `total` is undefined for streams |
| `uniqueFilename` | `boolean` | Append a random suffix (default: `true`) |
| `contentType` | `string` | MIME type; required for streams (Buffers and Files are detected from content) |
| `cacheControl` | `string` | `Cache-Control` for the stored object |
| `contentDisposition` | `string` | `Content-Disposition` for the stored object |
| `signal` | `AbortSignal` | Cancel the upload (`ABORTED` error) |
| `providerOptions` | `Record<string, unknown>` | Native parameters, e.g. S3 `StorageClass`. Never from client input |

### UploadResult

```typescript
interface UploadResult {
  id: string;
  storageKey: string;
  url: string;
  publicUrl?: string;
  size: number;
  format: string;
  width?: number;
  height?: number;
  provider: string;
  metadata: Record<string, unknown>;
  createdAt: Date;
}
```

| Field        | Type                      | Description                                                               |
| ------------ | ------------------------- | ------------------------------------------------------------------------- |
| `id`         | `string`                  | Unique identifier for the uploaded file                                   |
| `storageKey` | `string`                  | Provider-specific storage key (e.g., S3 object key, Cloudinary public ID) |
| `url`        | `string`                  | Direct URL to the file                                                    |
| `publicUrl`  | `string` (optional)       | Public URL. Omitted for private storage served through signed URLs        |
| `size`       | `number`                  | File size in bytes                                                        |
| `format`     | `string`                  | File format/extension                                                     |
| `width`      | `number`                  | Image width (if applicable)                                               |
| `height`     | `number`                  | Image height (if applicable)                                              |
| `provider`   | `string`                  | Provider name that handled the upload                                     |
| `metadata`   | `Record<string, unknown>` | Additional metadata                                                       |
| `createdAt`  | `Date`                    | Upload timestamp                                                          |

### TransformationOptions

```typescript
interface TransformationOptions {
```

### MediaProvider

```typescript
interface MediaProvider {
  readonly name: string;
  readonly features: ProviderFeatures;
  readonly native: unknown;

  upload(file: UploadInput, options?: UploadOptions): Promise<UploadResult>;

  uploadMultiple(files: UploadInput[], options?: UploadOptions): Promise<UploadResult[]>;
  deleteMultiple(ids: string[], options?: ResourceOptions): Promise<void>;

  // Optional capabilities
  getSignedUrl?(id: string, options?: SignedUrlOptions): Promise<string>;
  createUploadUrl?(options: SignedUploadOptions): Promise<SignedUploadTarget>;
  exists?(id: string, options?: ResourceOptions): Promise<boolean>;
  list?(options?: ListOptions): Promise<ListResult>;
  search?(query: SearchOptions): Promise<UploadResult[]>;
  copy?(fromId: string, toId: string, options?: ResourceOptions): Promise<UploadResult>;
  move?(fromId: string, toId: string, options?: ResourceOptions): Promise<UploadResult>;
  download?(id: string, options?: ResourceOptions): Promise<DownloadResult>;
  updateMetadata?(id: string, metadata: Record<string, unknown>, options?: ResourceOptions): Promise<void>;
```

## Errors

### MediaError

Structured error class with typed error codes and provider context.

```typescript
class MediaError extends Error {
  code: MediaErrorCode;
  provider: string;
  originalError?: unknown;
  details?: Record<string, unknown>;
}
```

### MediaErrorCode

```typescript
enum MediaErrorCode {
  // Upload errors
  UPLOAD_FAILED = 'UPLOAD_FAILED',
  FILE_TOO_LARGE = 'FILE_TOO_LARGE',
  INVALID_FILE_TYPE = 'INVALID_FILE_TYPE',
  NETWORK_ERROR = 'NETWORK_ERROR',

  // Authentication errors
  INVALID_CREDENTIALS = 'INVALID_CREDENTIALS',
  UNAUTHORIZED = 'UNAUTHORIZED',

  // Provider errors
  PROVIDER_ERROR = 'PROVIDER_ERROR',
  RATE_LIMITED = 'RATE_LIMITED',
  QUOTA_EXCEEDED = 'QUOTA_EXCEEDED',

  // Configuration errors (also: unsafe storage keys)
  INVALID_CONFIG = 'INVALID_CONFIG',
  MISSING_CREDENTIALS = 'MISSING_CREDENTIALS',

  // File errors
  FILE_NOT_FOUND = 'FILE_NOT_FOUND',
  DELETE_FAILED = 'DELETE_FAILED',

  // Operation errors
  ABORTED = 'ABORTED',             // cancelled through an AbortSignal; never retried
  NOT_SUPPORTED = 'NOT_SUPPORTED', // the provider lacks this operation
}
```

`isAbortError(error)` is true for `ABORTED` MediaErrors and DOM/Node `AbortError`s.

### createMediaError

Factory function for creating consistent `MediaError` instances (the message is taken from the original error):

```typescript
import { createMediaError, MediaErrorCode } from '@fluxmedia/core';

const error = createMediaError(
  MediaErrorCode.UPLOAD_FAILED,
  'cloudinary',
  originalError,
  { timeout: 30000 } // details
);
```

### PartialUploadError

Error type for custom upload code that can resume multipart uploads. `withRetry` passes its `uploadContext` to the next attempt. The built-in providers do not throw it: they abort failed multipart uploads and retry from the start.

```typescript
class PartialUploadError extends MediaError {
  uploadContext: PartialUploadContext;
}

interface PartialUploadContext {
  uploadId: string;
  key: string;
  completedParts: Array<{ partNumber: number; etag: string }>;
  provider: string;
}
```

## Plugin Types

### FluxMediaPlugin

```typescript
interface FluxMediaPlugin {
  name: string;
  version?: string;
  optional?: boolean; // If true, errors in hooks are caught and logged
  hooks: PluginHooks;
  init?: () => Promise<void> | void; // Called when plugin is registered
  destroy?: () => Promise<void> | void; // Called when plugin is unregistered
}
```

The `optional` flag enables graceful degradation — if an optional plugin's hook throws, the error is caught and the upload continues. This is ideal for non-critical plugins like analytics or metadata extraction.

### PluginHooks

```typescript
type UploadFn = (file: UploadInput, options: UploadOptions) => Promise<UploadResult>;

interface PluginHooks {
  beforeUpload?: (
    file: UploadInput,
    options: UploadOptions
  ) => Promise<{ file: UploadInput; options: UploadOptions } | void>;
  // Wrap the provider upload: retry, short-circuit (dedupe), time it…
  // The first registered plugin is the outermost wrapper.
  wrapUpload?: (next: UploadFn) => UploadFn;
  afterUpload?: (
    result: UploadResult,
    context: { file: UploadInput; options: UploadOptions }
  ) => Promise<UploadResult>;
  onError?: (
    error: Error,
    context: {
      file: UploadInput;
      options: UploadOptions;
      phase: UploadPhase;
      uploadResult?: UploadResult; // present for 'afterUpload'
    }
  ) => Promise<void>;
  beforeDelete?: (id: string) => Promise<string | void>;
  afterDelete?: (id: string) => Promise<void>;
  beforeGetUrl?: (
    id: string,
    transform?: TransformationOptions
  ) => Promise<{ id: string; transform?: TransformationOptions } | void>;
}
```

A failing `onError` hook is logged and never replaces the original error.

### UploadPhase

```typescript
type UploadPhase = 'beforeUpload' | 'upload' | 'afterUpload';
```

Indicates which phase of the upload pipeline the error occurred in, available in `onError` context.

### createPlugin Helper

```typescript
import { createPlugin } from '@fluxmedia/core';

const myPlugin = createPlugin(
  'my-plugin',
  {
    beforeUpload: async (file, options) => {
      return { file, options };
    },
  },
  { optional: true }
);
```

## Testing Utilities

Helpers for testing custom providers and upload logic.

### createMockProvider

Creates a mock `MediaProvider` for unit tests:

```typescript
import { createMockProvider, createMockUploadResult } from '@fluxmedia/core/testing';

const provider = createMockProvider({
  name: 'test-provider',
});

const result = await provider.upload(file);
```

### createProviderContractTests

Validates that a custom provider correctly implements the `MediaProvider` interface:

```typescript
import { createProviderContractTests } from '@fluxmedia/core/testing';

createProviderContractTests('MyProvider', () => new MyProvider({ ... }));
```

This runs a suite of tests verifying:

- Required properties (`name`, `features`)
- Feature matrix structure (transformations, capabilities, storage)
- All required methods exist (`upload`, `delete`, `get`, `getUrl`, `uploadMultiple`, `deleteMultiple`, `native`)
- `getUrl` returns valid URL strings
