# Getting Started

Learn how to install and configure FluxMedia in your project.

## Installation

Choose your package manager:

```bash npm2yarn
npm install @fluxmedia/core @fluxmedia/cloudinary
```

### Available Packages

Install only what you need:

```bash
# Core (required)
pnpm add @fluxmedia/core

# Pick a provider (each needs its SDK as a peer dependency)
pnpm add @fluxmedia/cloudinary cloudinary                                  # Transformations
pnpm add @fluxmedia/s3 @aws-sdk/client-s3 @aws-sdk/lib-storage            # AWS S3 / S3-compatible
pnpm add @fluxmedia/r2 @aws-sdk/client-s3 @aws-sdk/lib-storage            # Cloudflare R2
pnpm add @fluxmedia/gcs @google-cloud/storage                             # Google Cloud Storage
pnpm add @fluxmedia/azure @azure/storage-blob                             # Azure Blob Storage
pnpm add @fluxmedia/local                                                 # Local filesystem

# Signed URLs on S3/R2
pnpm add @aws-sdk/s3-request-presigner

# Optional: Official plugins
pnpm add @fluxmedia/plugins

# Optional: React integration
pnpm add @fluxmedia/react
```

For tests and local development, `MemoryProvider` from `@fluxmedia/core` needs no setup.

# Core (required)
pnpm add @fluxmedia/core

# Pick a provider
pnpm add @fluxmedia/cloudinary  # Full featured with transformations
pnpm add @fluxmedia/s3          # AWS S3
pnpm add @fluxmedia/r2          # Cloudflare R2

# Optional: Official plugins
pnpm add @fluxmedia/plugins

# Optional: React integration
pnpm add @fluxmedia/react
```

## Basic Usage

### Node.js / Server

```typescript
import { MediaUploader } from '@fluxmedia/core';
import { CloudinaryProvider } from '@fluxmedia/cloudinary';

// Create uploader with your provider
const uploader = new MediaUploader(
  new CloudinaryProvider({
    cloudName: process.env.CLOUDINARY_CLOUD_NAME!,
    apiKey: process.env.CLOUDINARY_API_KEY!,
    apiSecret: process.env.CLOUDINARY_API_SECRET!,
  })
);

// Upload a file
const result = await uploader.upload(fileBuffer, {
  folder: 'user-avatars',
  filename: 'avatar-123',
});

console.log(result.url); // https://res.cloudinary.com/...
console.log(result.id); // user-avatars/avatar-123-x1y2z3a4 (random suffix; uniqueFilename: false to keep the exact name)
console.log(result.storageKey); // Provider-specific storage key
console.log(result.format); // jpg
```

Folders and filenames are sanitized, and only top-level string, number and boolean `metadata` values are stored with the file.

### Streaming Uploads

FluxMedia accepts multiple input types — not just `File` and `Buffer`:

```typescript
import { createReadStream } from 'fs';

// Upload from Node.js Readable stream
const stream = createReadStream('/path/to/large-file.mp4');
const result = await uploader.upload(stream, {
  folder: 'videos',
  contentType: 'video/mp4', // streams cannot be sniffed, so set the type
});

// Upload from web ReadableStream
const response = await fetch('https://example.com/image.jpg');
const result = await uploader.upload(response.body!, {
  folder: 'imports',
  contentType: response.headers.get('content-type') ?? 'application/octet-stream',
});
```

A stream can only be read once, so stream uploads are never retried or sent to a fallback provider.

### With React

The browser asks your server for a signed upload target, then uploads straight to storage:

```tsx
import { useMediaUpload } from '@fluxmedia/react';

function UploadButton() {
  const { upload, cancel, uploading, progress, result, error } = useMediaUpload({
    mode: 'signed',
    signUrlEndpoint: '/api/upload/sign',
    accept: ['image/*'],
    maxSize: 10 * 1024 * 1024,
  });

  return (
    <input
      type="file"
      disabled={uploading}
      onChange={(e) => {
        const file = e.target.files?.[0];
        if (file) upload(file);
      }}
    />
  );
}
```

The endpoint is one handler:

```typescript
// app/api/upload/sign/route.ts
import { createSignedUploadHandler } from '@fluxmedia/core/server';

export const POST = createSignedUploadHandler(uploader, {
  authorize: (request) => getSessionUser(request),
  allowedTypes: ['image/jpeg', 'image/png', 'image/webp'],
  maxSize: 10 * 1024 * 1024,
  folder: (user) => `users/${user.id}`,
});
```

See [Secure Uploads](/docs/secure-uploads) for the proxy alternative and the security checklist.

## Using Multiple Providers

FluxMedia lets you use multiple providers in the same application with a consistent API:

```typescript
// Cloudinary for media
const uploader = new MediaUploader(
  new CloudinaryProvider({ ... })
);

// S3 for archives — same interface
import { S3Provider } from '@fluxmedia/s3';

const uploader = new MediaUploader(
  new S3Provider({
    region: 'us-east-1',
    bucket: 'my-bucket',
    accessKeyId: process.env.AWS_ACCESS_KEY!,
    secretAccessKey: process.env.AWS_SECRET_KEY!,
  })
);

// All your upload code stays exactly the same
await uploader.upload(file, { folder: 'uploads' });
```

## Fallback Providers

Configure automatic failover when the primary provider is unavailable:

```typescript
import { MediaUploader, MediaErrorCode } from '@fluxmedia/core';

const uploader = new MediaUploader(
  new CloudinaryProvider({ ... }),  // Primary
  [],                                // No plugins
  {
    fallbackProvider: new S3Provider({ ... }),  // Fallback
    fallbackOnErrors: [
      MediaErrorCode.NETWORK_ERROR,
      MediaErrorCode.RATE_LIMITED,
      MediaErrorCode.PROVIDER_ERROR,
    ],
    onFallback: (error, fromProvider, toProvider) => {
      console.warn(`Using ${toProvider} instead of ${fromProvider}: ${error.message}`);
    },
  }
);

// If Cloudinary fails with a qualifying error, S3 is used automatically
const result = await uploader.upload(file, { folder: 'uploads' });

// Pass the result (not just the ID) so later calls go to the provider that stored it
await uploader.delete(result);
```

## Upload with Abort

Cancel in-flight uploads using `AbortController`:

```typescript
const controller = new AbortController();

// Cancel after 30 seconds
setTimeout(() => controller.abort(), 30000);

const result = await uploader.upload(file, {
  folder: 'uploads',
  signal: controller.signal,
});
```

## Progress Tracking

Track upload progress at two levels:

```typescript
const result = await uploader.upload(file, {
  folder: 'uploads',
  onProgress: (percent) => {
    // Normalized 0-100 percentage
    progressBar.style.width = `${percent}%`;
  },
  onByteProgress: (loaded, total) => {
    // Raw byte counts for precise tracking
    console.log(`${loaded}/${total} bytes`);
  },
});
```

## Feature Detection

Check if a provider supports specific features:

```typescript
if (uploader.supports('transformations.resize')) {
  // Apply resize transformation
  const url = uploader.getUrl(id, { width: 200, height: 200 });
}

if (uploader.supports('capabilities.videoProcessing')) {
  // Provider supports video processing
}
```

## Private Files

Leave the public URL off and hand out short-lived links:

```typescript
const result = await uploader.upload(file);
const url = await uploader.getSignedUrl(result, { expiresIn: 300 });
```

Each provider page explains how to make storage private (for example `publicUrl: false` on S3, or no `publicUrl` on R2).
