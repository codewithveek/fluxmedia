# Cloudinary Provider

Full-featured media management with on-the-fly transformations.

## Installation

```bash
pnpm add @fluxmedia/core @fluxmedia/cloudinary cloudinary
```

## Configuration

```typescript
import { MediaUploader } from '@fluxmedia/core';
import { CloudinaryProvider } from '@fluxmedia/cloudinary';

const uploader = new MediaUploader(
  new CloudinaryProvider({
    cloudName: 'your-cloud-name',
    apiKey: 'your-api-key',
    apiSecret: 'your-api-secret',
    secure: true, // Use HTTPS (default: true)
  })
);
```

### Configuration Options

| Option               | Type    | Required | Description                                                         |
| -------------------- | ------- | -------- | ------------------------------------------------------------------- |
| `cloudName`          | string  | Yes      | Your Cloudinary cloud name                                          |
| `apiKey`             | string  | Yes      | API key from dashboard                                              |
| `apiSecret`          | string  | Yes      | API secret (keep secure!)                                           |
| `secure`             | boolean | No       | Use HTTPS URLs (default: true)                                      |
| `authTokenKey`       | string  | No       | Token-based auth key: expiring URLs for private assets, with transformations |
| `secureDistribution` | string  | No       | Custom delivery domain (CNAME / private CDN)                        |

Credentials are sent with each request rather than through the global `cloudinary.config()`, so providers for different accounts can run in one process.

## Upload with Transformations

```typescript
const result = await uploader.upload(file, {
  folder: 'avatars',
  tags: ['user', 'profile'],
  transformation: {
    width: 400,
    height: 400,
    fit: 'cover',
    quality: 80,
    format: 'webp',
  },
});
```

## On-the-fly URL Transformations

```typescript
// Get URL with transformations
const thumbnail = uploader.getUrl(result.id, {
  width: 150,
  height: 150,
  fit: 'cover',
  format: 'webp',
});

// Multiple sizes
const sizes = {
  small: uploader.getUrl(id, { width: 100 }),
  medium: uploader.getUrl(id, { width: 400 }),
  large: uploader.getUrl(id, { width: 800 }),
};
```

## Batch Uploads

```typescript
const results = await uploader.uploadMultiple(files, {
  folder: 'batch-upload',
  concurrency: 5,
  onBatchProgress: (completed, total) => {
    console.log(`Uploaded ${completed}/${total} files`);
  }
});
```

## Delete Files

```typescript
// Pass the upload result: the provider knows the resource type (image, video, raw)
await uploader.delete(result);

// With only an ID, give the resource type, or the provider tries image, video and raw in turn
await uploader.delete(videoId, { metadata: { resourceType: 'video' } });

// Delete multiple
await uploader.deleteMultiple(['id1', 'id2', 'id3']);
```

## Private Assets and Signed URLs

```typescript
// Stored as "authenticated": no public URL, readable only through signed URLs
const result = await uploader.upload(file, { public: false });

const url = await uploader.getSignedUrl(result, { expiresIn: 600 });
```

For private assets, signed URLs use Cloudinary's private download API (original file, real expiry), or, with `authTokenKey`, token-authenticated delivery URLs that also support transformations. Public assets are readable by anyone, so `getSignedUrl` returns their normal URL. Pass the `UploadResult` to skip an Admin API lookup.

## Direct Browser Uploads

`createUploadUrl` returns signed form fields for a `POST` to the Cloudinary upload API. The signature fixes the public ID, tags, context, delivery type and allowed formats; it cannot cap the file size, so use an upload preset with limits (or the proxy handler) when size matters. See [Secure Uploads](/docs/secure-uploads).

## Listing and Search

```typescript
const page = await uploader.list({ folder: 'products', limit: 50 });
const results = await uploader.search({ query: 'shoe', tags: ['summer'] });
```

Both use the Search API, which indexes new uploads asynchronously. `copy`, `move` (rename), `download`, `exists` and `updateMetadata` (context) are also supported.

## Native SDK Access

Access the full Cloudinary SDK for advanced operations. The global config is not set, so pass credentials with each call:

```typescript
const cloudinary = uploader.provider.native; // null until the first request

const credentials = {
  cloud_name: process.env.CLOUDINARY_CLOUD_NAME,
  api_key: process.env.CLOUDINARY_API_KEY,
  api_secret: process.env.CLOUDINARY_API_SECRET,
};

await cloudinary.uploader.explicit('sample', {
  ...credentials,
  type: 'upload',
  eager: [{ effect: 'sepia' }],
});
```
